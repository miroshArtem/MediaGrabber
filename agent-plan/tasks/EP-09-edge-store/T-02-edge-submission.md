## Goal

Submit extension to Microsoft Edge Add-ons store.

---

## Subtasks

- [ ] Create Microsoft developer account
- [ ] Package extension for Edge
- [ ] Create Edge Add-ons listing
- [ ] Submit for review
- [ ] Publish after approval

---

## Developer Account

1. Go to https://partner.microsoft.com/dashboard/microsoft-edge/
2. Sign in with Microsoft account
3. Register as Edge extension developer

---

## Listing Details

| Field | Value |
|-------|-------|
| Name | MediaGrabber |
| Description | Download online videos with quality selection |
| Category | Productivity |
| Privacy Policy URL | (Your hosted privacy policy) |

---

## Submission Steps

1. **Partner Center Dashboard**
   - Go to Microsoft Edge extension dashboard
   - Click "Create new extension"

2. **Upload Package**
   - Upload .zip file
   - Fill in store listing details

3. **Submit**
   - Complete all required fields
   - Submit for certification

4. **After Approval**
   - Extension is published to Microsoft Edge Add-ons
